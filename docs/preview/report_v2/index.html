要看的重點

  • A4、不切斷：每一頁是獨立排好的 A4，圖表、表格列、段落都不會被切；長表在列與列之間換頁、續頁重複表頭並標「（續）」；太寬的表自動縮字、再不夠就整張縮小。
  • 第一頁：標題 → 重點摘要 3～5 點（取自已核對的「總結」）＋右側「估值位階」區塊 → 四格關鍵數字 → 營收與 EPS 圖 → 事件摘句（重點摘要就是總結的各環節，所以不再另放總結一行）。
  • 評等：站上規則是「不放評等、目標價、潛在漲幅」（Evans 09-28），所以評等的位置放估值位階（本益比、淨值比、ROE、殖利率），並註明不提供評等。要不要改成真的評等請 Evans 裁示。
  • 前言進附錄：「事件」「公司簡介」超過 260 字，第一頁只留開頭幾句＋「全文見附錄」，全文放最後的附錄。
  • 每頁：頁首（GEA 戰情・AI 研究報告／代號名稱資料日）、頁尾（僅供參考＋下載日＋第 n／N 頁）、浮水印照舊畫進像素。
  • EDM 圖卡（新）：1080×1350 直式（IG、LINE 分享尺寸），架構參考藏鋒兩張圖：大標、四格關鍵數字、營收與 EPS 圖、重點 3 點、後續追蹤 3 點、風險一行、下一步一行（總結第 4 環節）。文字只截短、不改寫。
  • 產品線表同一列（名稱＋數字都一樣）重複出現的只顯示一次（資料本身沒改）。
