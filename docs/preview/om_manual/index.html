一、安裝前準備

GEA 的策略部位一變，訊號就經雲端中繼送到您電腦上的 GEA 下單機，由它直接用您的國票 API 下單。中繼只轉送訊號，看不到您的帳號密碼；您的電腦不用開任何對外的埠、不用固定 IP。

1. 電腦需求

  • 64 位元 Windows 10／11、能上網（https 443）。
  • 穩定、不超頻、不會自動睡眠的電腦（下單機開著才會下單）。
  • 電腦時間要準：Windows「自動設定時間」打開（時間差太多，訊號會被當成舊訊號拒收）。
  • 同一台電腦不要再開其他會讀同一個訊號的下單程式（同一個訊號會下兩次單）。

2. 國票帳號與憑證

  • 國票期貨帳號，且已開通 API（流程見下面；還沒開通的話精靈第 2 步會帶您走）。
  • 國票憑證檔（.pfx）與憑證密碼（預設跟電子交易密碼一樣）。
  • 身分證字號、電子交易密碼。期貨帳號不用記，精靈第 2 步會列出來讓您選。

3. 要準備的東西（清單）

4. 國票 API 開通流程（第一次用一定要走完）

  1. 簽署：在國票理財 E 管家 APP 線上簽「API 風險預告書暨使用同意書」。
  2. 營業員申請測試環境；測試金放好後營業員會通知您。
  3. 送 10 筆測試單：在期貨測試時段（平日 11:15～13:45、16:15～隔天 01:30），精靈第 2 步按「開啟 API 開通精靈」：用憑證登入測試環境送 10 筆限價買單（掛著不會成交），把委託書號給營業員。
  4. 營業員申請正式環境；開通後回精靈第 2 步按「登入檢查」，帳號變成可以選就完成了。

二、下載與執行安裝程式

  1. 下載：營業員傳給您的開通訊息裡附有安裝檔下載網址，下載 GEA下單機Setup_20261117a.exe。
  2. 按兩下安裝檔，一路「下一步」→「安裝」→「完成」。Windows 問「是否允許」請按「是」。
  3. 電腦缺微軟 .NET Framework 4.8 時，安裝檔會自動從微軟網站下載（約 120 MB，驗證過才安裝）；要重開機就重開，登入 Windows 後安裝自動接著進行。
  4. 國票三支元件、換月對照表都內建在安裝檔裡，不用另外下載。
  5. 裝在 C:\GEA_om；桌面有「GEA 下單機」與「GEA 下單機設定」兩個捷徑；開機自動啟動已自動建好，不需要自己設定工作排程。
  6. 完成後自動開啟設定精靈（下一章）。
這台電腦已經裝過：直接執行新的安裝檔就好，會自動停掉正在跑的下單機、備份、換新版；國票資料、部位、策略設定、記錄都保留，設定精靈已通過的步驟會直接打勾。

三、設定精靈：第 0～6 步

畫面最上方固定寫「本下單機只支援國票期貨 API（國內期貨）」。左邊是第 0～6 步，每一步通過才會亮「下一步」；選單「工具」可以單獨重跑第 1～5 步。精靈記得已通過的步驟，關掉再開會接著做；桌面「GEA 下單機設定」可以再開。

第 3 步　開通碼

填營業員給的 8 碼開通碼，按「開通」。開通時這台電腦會綁到您的身分證（GEA 只收到加密過的雜湊，看不到身分證字號），接著連線 GEA 中繼、列出您訂閱的策略；新訂的策略自動加進策略設定（預設微台 1 口）。

卡住了：畫面寫怎麼辦
開通碼不對（或已經用過）／已過期核對 8 碼（沒有 0、O、1、I）；開通碼 24 小時內有效、只能用一次，過期請營業員重新產生。
身分證與開通時不同，請聯絡營業員這個代號已經綁了別的身分證。換人使用要請營業員處理，GEA 也會收到 TG 通知。
同一個身分證已經有別台在收同一支策略同一支策略同一時間只能一台真單：先關掉另一台，或請營業員設定。
連不到中繼／15 秒內沒連上確認能上網；防毒把 C:\GEA_om\ 加例外；公司網路請放行 *.workers.dev 的 443。
服務期限已到找營業員續約；只停止接收新訊號，不會平倉。

第 4 步　電腦設定

下單機要整天開著：檢查電源（接電不睡眠、不休眠）、Windows Update（使用時段 08:00～02:00 不重開機）、開機自動啟動（安裝時已建好）、自動登入 Windows（預設不開）。有 ✗ 的按「一鍵設好」。

卡住了：畫面寫怎麼辦
按「一鍵設好」後還是 ✗Windows 問「是否允許」要按「是」；公司電腦被網管鎖住的話請網管協助。
停電或 Windows 更新重開後下單機沒啟動重新開機後要登入 Windows 才會啟動；不想每次手動登入可按「開啟自動登入…」（會先顯示安全提醒）。

第 5 步　模擬演練

用假的國票 API（不會送出任何真單）跑一遍：新倉 → 加碼 → 平倉一部分 → 反手 → 自動換月，每一步都要 ✓。

卡住了：畫面寫怎麼辦
模擬演練沒過把畫面截圖、按「工具 → 開記錄資料夾」把當天記錄檔一起給營業員。

第 6 步　啟動

全部通過後按「啟動 GEA 下單機」。真單（非模擬）會先跳確認：同一個期貨帳號如果已經有別台下單機在下單會重複下單，要勾「我確認這個帳號只有這台在下單」才能按確定（直接按 Enter＝取消）。之後登入 Windows 就自動啟動；視窗最上面一行要看到「國票正式｜雲端中繼」，log 有「已連上中繼」。

卡住了：畫面寫怎麼辦
「下一步」一直是灰的前面那一步還沒通過：看那一步的紅字照著做；左邊步驟清單打勾的才算通過。
想重新檢查某一步選單「工具」可以單獨重跑第 1～5 步；精靈會記住已通過的步驟，關掉再開會接著做。

4. 帳戶區「補」：部位跟訊號對不上時

按「補」→ 先重新向券商查詢庫存（請確認券商回傳的部位正確）→ 顯示要補幾口 → 確認後才送單（範圍市價）。動作會寫記錄並 TG 通知 GEA。對帳燈 ✗ 時就用這顆處理。

5. 帳戶區「清」：平掉這個商品全部庫存

按「清」要確認兩次，第二次要輸入商品代碼，才會平掉這個商品的全部庫存。清掉之後這個商品的策略會停住，等下一筆訊號照規則恢復。

6. 策略區：跟單開關、日誌、進階

每支策略一列：部位、成本、跟單開關、日誌、進階。倍數不是 1 時寫在商品後面（例「小台 MXF ×2」）。右上角「全部暫停跟單」一次關掉所有跟單中的策略。跟單開關的規則見第五章 3。

7. 進階（每支策略一組：商品、口數倍數與最大持倉、下單方式、換倉）

四個分頁：商品（台指／小台／微台）、口數（下單倍數、最大持倉限制，超過就不送並 TG）、下單（範圍市價或限價）、換倉（自動換倉、換倉明細）。改完按「儲存設定」。不改就用預設：微台 1 口、範圍市價、結算前一交易日 13:45 自動換倉。

8. 換倉編輯

換倉明細每一列右邊按「編輯」：合約月份、換倉日期、時間、自動換倉。勾「全部套用」會把這一列的提前天數與時間套到同商品所有策略（儲存前先確認套用幾支、幾個月）。

9. 日誌

分類：全部／系統／策略／訊號／委託／成交／異常／API，可選日期。有問題先看「異常」。

10. 左下角：版本與更新

左下角顯示「目前版本」；GEA 出新版時會變成「有新版本 → 更新」按鈕（第六章 1）。

五、日常使用

1. 開機

  • 登入 Windows 後下單機自動啟動（停電、Windows 更新重開也一樣，要登入 Windows 才會啟動；不想每次手動登入可在精靈第 4 步「開啟自動登入…」，預設不開）。
  • 每次開機連上中繼，會把中繼保留的訊號從頭補收一次，用來確認每支策略的最新狀態。開機前已經處理過的舊訊號只記狀態、不會下單；日誌會逐則寫「補收 #序號 策略（開機前已處理過 → 只記狀態、不下單）」，補收完寫「補發完成：N 則…」。看到這些是正常的，不是重複下單。
  • 補收的舊訊號裡無法驗證或過時的，會彙總成一則 TG「補發 N 則舊訊號無法採用」，不影響之後的即時訊號。

2. 收訊號與下單

  • 訊號一到，跟單中的策略照「目標部位」下單（下單方式預設範圍市價，可在「進階 → 下單」改）；不跟單的策略只記錄訊號部位、不送單。
  • 帳戶區「訊號口數」＝跟單中的策略加總；「庫存」＝券商回傳（已扣掉客戶保留部位）；兩邊一致對帳燈 ✓，不一致 ✗（用「補」處理）。
  • 超過「最大持倉」的單不送，並 TG 通知。
日誌開頭符號意思
✓ 訊號 GEA5「20261025 150718,0,49040.00」收到並處理了一筆訊號（時間,部位,價格）
· → 下單機 … Sell 1 口 …送出的委託內容
· ✓ 下單機 … 成交 … → 帳上 0成交、帳上部位更新
✗ 拒單 …（過時）訊號太舊被拒（多半是電腦時間不準）
· 略過（不是這台的策略）正常：這台只收您訂閱的策略

3. 跟單開關（暫停／恢復）

每支策略一個「跟單」開關（開＝訊號會送單；關＝只收訊號、不送單）。開關狀態會存檔，重開電腦、重開下單機都會恢復上次的樣子；每次開／關都會寫記錄並 TG 通知。

動作下單機怎麼做
有部位時把「跟單」關掉先跳確認框；不會平倉。帳上那幾口記成「客戶保留部位」，策略區顯示「客戶保留 多 N 口」；對帳時從庫存扣掉，不會亮 ✗；按「補」也不會去補它
關掉後要平掉保留部位按該商品的「清」（連保留部位一起平，平完保留歸零）；或自己在券商軟體平掉，下單機下次查庫存時發現已經平掉就自動歸零
重新打開時，訊號還有部位不會馬上送單，策略區顯示「等待下一個訊號（目前訊號部位 多 2 口）」；下一則訊號來時直接對齊目標（保留部位算進去，不會重複下）
重新打開時，訊號 0 口立即恢復跟單，下一則訊號照常下單
關掉期間訊號照收、記錄訊號部位，不送任何單
「全部暫停跟單」（策略區右上角）確認一次，把所有跟單中的策略一起關掉；部位照上面「關掉」的規則記成保留，不平倉
營業員取消某支策略的訂閱下次連上時那支自動改成「關」，帳上部位記成保留、不平倉

建議：要自己在券商軟體處理跟單中的部位，先把那支策略的「跟單」關掉，再操作。

4. 換月（下單機自動處理）

  1. 新開的倉一律下新合約；舊合約部位只會平、不會加。
  2. 反手拆兩張：舊合約部位遇到反手 → 拆成「平舊合約」＋「新合約建倉」。
  3. 自動換倉：照「進階 → 換倉」的時間（預設結算前一交易日 13:45）送「平舊＋建新」；沒成交每分鐘重試，還不成交發 TG 紅色警報，請立刻到券商軟體手動換月。
  4. 換倉一律用範圍市價。第一次遇到結算日，請留意 TG 通知與券商軟體上的部位。

5. 模擬與真單

  • 真單：最上方紅底「⚠ 真單模式」。啟動時會跳確認框，分兩行列出「跟單中：…」「只收訊號：…」，勾「我確認這個帳號只有這台在下單」才能按確定（直接按 Enter＝取消）。
  • 模擬：最上方橘底「模擬環境（假國票，不下單）」，視窗標題寫「（模擬，不下單）」，並有紅色橫幅「模擬模式中：不登入國票、不會下單」。
  • 切換：開桌面「GEA 下單機設定」，選單「工具 → 模擬模式（假國票，不登入、不下單）」打勾＝模擬、取消打勾＝真單；切換後要從第 2 步（國票 API 權限）重跑到第 6 步「啟動」。
  • 同一個身分證兩台電腦：另一台已經用真單在跟同一支策略時，後開的這台會自動變成模擬（只收訊號、不下單、不會斷線），右上顯示「模擬（同身分證另一台真單中，不下單）」並 TG 通知。關掉重開會再判斷一次。

6. 訂閱策略

  • 訂閱由營業員／GEA 設定，您不用重新開通。
  • 新訂閱的策略：下次連上中繼時自動出現在策略區，預設「不跟單」；中繼會立刻送來那支策略的最新部位，下單機馬上對帳（日誌「快照對帳：一致 N 支」），不會因此下單。看過訊號、確認口數後再自己把「跟單」打開。
  • 取消訂閱：沒有部位就從畫面拿掉；還有部位會改成「不跟單」、記成客戶保留部位，不會自動平倉，請自己決定怎麼處理。

7. 主機代號

主畫面最上方深色列右側顯示「主機代號 c＋9 碼數字」，旁邊有「複製」按鈕：按一下就複製到剪貼簿（按鈕會短暫變成「✓ 已複製」）。要請 GEA 改訂閱、查連線或處理問題時，直接把代號貼給營業員或 GEA，最快找到您這台。還沒開通時顯示「（還沒開通）」、按鈕不能按。

六、更新、重開與斷線自動重登

1. 更新新版

GEA 出新版時，左下角會變成「有新版本 → 更新」按鈕（只提示、不會自己更新）：按下去會下載、驗證、關掉下單機、安裝新版、重新啟動並重新對帳；設定、部位全部保留。任何時間都能更新；有部位或在交易時段時會先跳確認框：更新期間約 30～60 秒收不到訊號、不會跟單，裝完自動開回來並對帳（這段時間剛好有新訊號，該策略會先停止並 TG 通知，照通知處理）。按「確定」才更新。

2. 關閉與重開下單機

  • 按視窗右上角 X：還有跟單中的策略會先問（列出策略與帳上口數，預設「否」）；關掉後不收訊號、不下單，帳上部位不會平倉。確定關閉會寫記錄並 TG 通知。
  • 重開：按兩下桌面「GEA 下單機」。重開後照開機流程補收訊號、對帳（第五章 1）。

3. 國票斷線自動重新登入

國票連線斷掉時，下單機會自己重新登入：斷線 3 秒後試第一次，之後每 30 秒一次，一輪最多 200 次；一輪都失敗就休息 10 分鐘再來一輪（只在交易時段）。重登中主畫面「券商」燈是紅的、寫「自動重連中（第 N 次）」；登入恢復會發 TG。

斷線期間收到的訊號不會事後補送（每收到一則都會發 TG）。登入恢復後照開機一樣對帳：訊號跟帳上部位一樣就照常跟單；不一樣就停這支策略、發 TG、不自動追單——請到券商軟體確認實際部位，再按「補」由您決定要不要補單。

4. 不是下單機下的成交（例：在國票 App 手動平倉）

國票回報一筆對不到任何策略的成交時，下單機會在幾秒內向國票查庫存，跟「帳上部位＋客戶保留部位」比對：一致就沒事；不一致就停這個商品所有跟單中的策略並發 TG，之後訊號回到帳上部位也不會自動恢復。連續 3 次查不到庫存也會全部停下並 TG。處理方式：到券商軟體確認實際部位，照實際部位改好帳本（或請 GEA 協助）後重開下單機；重開後還是不一致，按「補」決定要不要補單。
