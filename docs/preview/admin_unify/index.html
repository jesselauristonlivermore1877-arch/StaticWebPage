會員和下單機客戶合成一筆（Evans 已裁示，照這個做）

1. 以中繼 users 為主表，加欄位 web_ok（看盤區能不能登入）、contact；會員站 members 加 cust_id 指向中繼代號，原本的 subs、exp、on_ 改成「只讀快取」。
2. 會員站讀中繼：Worker 對 Worker 呼叫（service binding，不經公開網路）GET /admin/customer?id=，回訂閱、到期、啟用、上架清單；快取 60 秒。
3. 合併既有資料（一次性，先乾跑）：用姓名＋聯絡配對，印「配對成功／只在一邊／兩邊訂閱或到期不一樣」三張表給 Evans 看；不一樣的以中繼為準（Evans 11-05 定案），Evans 點頭才寫入。只在看盤區的會員在中繼補建一筆（subs 照會員站、不發開通碼）。
4. 管理功能搬家：會員站的會員管理、原型研究、客戶選單都搬到中繼 /admin；會員站管理 API 保留給 /admin 呼叫，管理頁籤拿掉。
5. 開通碼：/admin 只留「產生開通碼」；客戶列表那顆叫「重新產生開通碼」；傳送端收進「進階」。TG「/開通碼」照舊。
6. 測試：中繼 test.mjs＋會員站 test.mjs 加：改訂閱一次兩邊生效、下架一次兩邊不見、停用一次兩邊擋、客戶網址看不到三個頁籤（打網址 403）、訊號區只出現已訂閱的策略。全過才請 Evans 同意部署。
