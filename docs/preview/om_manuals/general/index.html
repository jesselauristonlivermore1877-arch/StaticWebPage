適用對象：用自己電腦上 MultiCharts／CT PRO 的策略訊號檔，透過國票 API 自動下單的客戶（訊號在自己電腦上，不經過 GEA 雲端）

本下單機只支援國票期貨 API（國內期貨）

一、安裝前準備

您的 MultiCharts／CT PRO 策略把部位寫進這台電腦的訊號檔，同一台電腦上的 GEA 下單機一看到部位改變，就用您的國票 API 下單。訊號不經過網路上的任何中繼，國票資料只加密存在這台電腦；您的電腦不用開任何對外的埠、不用固定 IP。

1. 電腦需求

  • 64 位元 Windows 10／11、能上網（https 443）。
  • 穩定、不超頻、不會自動睡眠的電腦（下單機開著才會下單）。
  • 電腦時間要準：Windows「自動設定時間」打開（時間差太多，訊號會被當成舊訊號拒收）。
  • 同一台電腦不要再開其他會讀同一個訊號的下單程式（同一個訊號會下兩次單）。

2. 國票帳號與憑證

  • 國票期貨帳號，且已開通 API（流程見下面；還沒開通的話精靈第 2 步會帶您走）。
  • 國票憑證檔（.pfx）與憑證密碼（預設跟電子交易密碼一樣）。
  • 身分證字號、電子交易密碼。期貨帳號不用記，精靈第 2 步會列出來讓您選。

3. 要準備的東西（清單）

項目從哪裡來
64 位元 Windows 10／11 電腦（能上網、不睡眠）自己準備

4. 國票 API 開通流程（第一次用一定要走完）

  1. 簽署：在國票理財 E 管家 APP 線上簽「API 風險預告書暨使用同意書」。
  2. 營業員申請測試環境；測試金放好後營業員會通知您。
  3. 送 10 筆測試單：在期貨測試時段（平日 11:15～13:45、16:15～隔天 01:30），精靈第 2 步按「開啟 API 開通精靈」：用憑證登入測試環境送 10 筆限價買單（掛著不會成交），把委託書號給營業員。
  4. 營業員申請正式環境；開通後回精靈第 2 步按「登入檢查」，帳號變成可以選就完成了。

二、下載與執行安裝程式

  1. 下載：營業員或 GEA 給您的安裝檔下載網址，下載 GEA下單機Setup_20261127b.exe。
  2. 按兩下安裝檔，一路「下一步」→「安裝」→「完成」。Windows 問「是否允許」請按「是」。
  3. 電腦缺微軟 .NET Framework 4.8 時，安裝檔會自動從微軟網站下載（約 120 MB，驗證過才安裝）；要重開機就重開，登入 Windows 後安裝自動接著進行。
  4. 國票三支元件、換月對照表都內建在安裝檔裡，不用另外下載。
  5. 裝在 C:\GEA_om；桌面有「GEA 下單機」與「GEA 下單機設定」兩個捷徑；開機自動啟動已自動建好，不需要自己設定工作排程。
  6. 完成後自動開啟設定精靈（下一章）。
這台電腦已經裝過：直接執行新的安裝檔就好，會自動停掉正在跑的下單機、備份、換新版；國票資料、部位、策略設定、記錄都保留，設定精靈已通過的步驟會直接打勾。

三、設定精靈：第 0～6 步

畫面最上方固定寫「本下單機只支援國票期貨 API（國內期貨）」。左邊是第 0～6 步，每一步通過才會亮「下一步」；選單「工具」可以單獨重跑第 1～5 步。精靈記得已通過的步驟，關掉再開會接著做；桌面「GEA 下單機設定」可以再開。

下面每張圖都是範例畫面（假資料）。國票資料只用 Windows 加密存在這台電腦（C:\GEA_om\ibf_cred.txt），只有這台電腦的這個 Windows 使用者解得開；換電腦或換 Windows 使用者要重做第 1～3 步。

第 0 步　安裝檢查

確認這台是 64 位元 Windows、有 .NET Framework 4.8（缺的話自動從微軟官方網站下載安裝，下載後先比對檢查碼才執行）、國票三支元件載入得了（只檢查元件，沒有登入、沒有下單）。下面訊號來源保持預設「本機訊號」＝讀這台電腦的策略訊號檔（MultiCharts／CT PRO 產生）直接下單：按「選擇…」選訊號檔資料夾、選格式（CT PRO 9 欄或 MoneyPrinter 三欄）、填每支策略最大口數（預設 2）。

32 位元 Windows國票 API 元件只有 64 位元版，這台不能用：換一台 64 位元 Windows 10／11。

第 1 步　憑證檢查

按「選擇…」選國票憑證檔（.pfx），填憑證密碼，按「檢查憑證」。程式讀出憑證上的身分證字號與到期日（只在這台電腦讀，不送出去）。

卡住了：畫面寫怎麼辦
無效憑證：憑證密碼不對憑證密碼通常跟電子交易密碼一樣；忘了請到國票網站或 APP 重新申請憑證。
無效憑證：已過期到國票網站或 APP 更新憑證，選新的 .pfx 檔再按一次。
這張是其他券商的憑證本下單機只支援國票期貨，請選國票發的憑證（檔名通常有身分證字號）。
不是券商的憑證選錯檔案了（例：自然人憑證、網站憑證），請選國票下載的 .pfx。

第 2 步　國票 API 權限

用剛才的憑證登入國票正式環境，只查詢、不下單，列出這個身分證底下的期貨帳號。已開通 API 的帳號可以選；沒開通的是灰字、選不到。國票回的原文一律存在 C:\GEA_om\logs\ibf_raw_messages.txt。

第 3 步　訊號來源

按「檢查訊號來源」：檢查訊號檔資料夾在、每個 .txt 都是第 0 步選的格式（檔名＝策略代碼，例 GEA5.txt），把找到的策略加進策略設定（預設微台 1 口）；Telegram 通知選填（填您自己機器人的 token 和 chat id，下單、拒單會傳給您；不填只寫記錄）。

卡住了：畫面寫怎麼辦
找不到訊號檔資料夾／資料夾裡沒有 .txt回第 0 步按「選擇…」重選 MultiCharts／CT PRO 寫訊號檔的資料夾；先讓 MC 產生訊號檔再檢查。
N 個檔不是「CT PRO 9 欄」（或三欄）第 0 步改成對的格式，或把不是訊號檔的 .txt 移出這個資料夾。

第 4 步　電腦設定

下單機要整天開著：檢查電源（接電不睡眠、不休眠）、Windows Update（使用時段 08:00～02:00 不重開機）、開機自動啟動（安裝時已建好）、自動登入 Windows（預設不開）。有 ✗ 的按「一鍵設好」。

卡住了：畫面寫怎麼辦
按「一鍵設好」後還是 ✗Windows 問「是否允許」要按「是」；公司電腦被網管鎖住的話請網管協助。
停電或 Windows 更新重開後下單機沒啟動重新開機後要登入 Windows 才會啟動；不想每次手動登入可按「開啟自動登入…」（會先顯示安全提醒）。

第 5 步　模擬演練

用假的國票 API（不會送出任何真單）跑一遍：新倉 → 加碼 → 平倉一部分 → 反手 → 自動換月，每一步都要 ✓。

卡住了：畫面寫怎麼辦
模擬演練沒過把畫面截圖、按「工具 → 開記錄資料夾」把當天記錄檔一起給營業員。

第 6 步　啟動

全部通過後按「啟動 GEA 下單機」。真單（非模擬）會先跳確認：同一個期貨帳號如果已經有別台下單機在下單會重複下單，要勾「我確認這個帳號只有這台在下單」才能按確定（直接按 Enter＝取消）。之後登入 Windows 就自動啟動；視窗最上面一行要看到「本機訊號」，「接收狀態」綠燈寫訊號檔資料夾和最後一筆訊號。

卡住了：畫面寫怎麼辦
「下一步」一直是灰的前面那一步還沒通過：看那一步的紅字照著做；左邊步驟清單打勾的才算通過。
想重新檢查某一步選單「工具」可以單獨重跑第 1～5 步；精靈會記住已通過的步驟，關掉再開會接著做。

四、主畫面：每個按鈕與狀態燈

精靈通過後（以後登入 Windows 自動開）就是這個畫面。下面都是範例畫面（假資料）。

1. 首頁

右側是狀態燈；中間「帳戶」每個商品一列（均價、訊號口數、庫存、對帳燈 ✓／✗、「補」「清」）；下面「策略」每支策略一列（部位、成本、跟單開關、日誌、進階）。

2. 最上方深色列

位置意思
左側模式標示真單＝紅底「⚠ 真單模式」；模擬＝橘底「模擬環境（假國票，不下單）」

3. 狀態燈

狀態燈綠燈紅燈怎麼辦
券商連線已登入國票看日誌「API」分頁的原因；斷線時會自動重登（第六章 3），久未恢復就重開下單機
接收狀態本機訊號：燈上寫訊號檔資料夾和最後一筆訊號訊號被拒（過時、超過最大口數、格式不對）時轉紅並寫原因：照原因修好訊號檔或設定，這支策略下一筆正常訊號自動恢復（第五章 2）
傳送狀態委託送出、券商回報正常最近一筆委託被拒或逾時：看「委託」與日誌「異常」，到券商軟體核對
憑證有效（剩幾天到期）30 天內到期轉黃並 TG：到國票網站或 APP 更新，再跑精靈第 1 步

4. 帳戶區「補」：部位跟訊號對不上時

按「補」→ 先重新向券商查詢庫存（請確認券商回傳的部位正確）→ 顯示要補幾口 → 確認後才送單（範圍市價）。動作會寫記錄並 TG 通知 GEA。對帳燈 ✗ 時就用這顆處理。

5. 帳戶區「清」：平掉這個商品全部庫存

按「清」要確認兩次，第二次要輸入商品代碼，才會平掉這個商品的全部庫存。清掉之後這個商品的策略會停住，等下一筆訊號照規則恢復。

6. 策略區：跟單開關、日誌、進階

每支策略一列：部位、成本、跟單開關、日誌、進階。倍數不是 1 時寫在商品後面（例「小台 MXF ×2」）。右上角「全部暫停跟單」一次關掉所有跟單中的策略。跟單開關的規則見第五章 3。

7. 進階（每支策略一組：商品、口數倍數與最大持倉、下單方式、換倉）

四個分頁：商品（台指／小台／微台）、口數（下單倍數、最大持倉限制，超過就不送並 TG）、下單（範圍市價或限價）、換倉（自動換倉、換倉明細）。改完按「儲存設定」。不改就用預設：微台 1 口、範圍市價、結算前一交易日 13:45 自動換倉。

8. 換倉編輯

換倉明細每一列右邊按「編輯」：合約月份、換倉日期、時間、自動換倉。勾「全部套用」會把這一列的提前天數與時間套到同商品所有策略（儲存前先確認套用幾支、幾個月）。

9. 日誌

分類：全部／系統／策略／訊號／委託／成交／異常／API，可選日期。有問題先看「異常」。

10. 左下角：版本與更新

左下角顯示「目前版本」；GEA 出新版時會變成「有新版本 → 更新」按鈕（第六章 1）。

五、日常使用

1. 開機

  • 登入 Windows 後下單機自動啟動（停電、Windows 更新重開也一樣，要登入 Windows 才會啟動；不想每次手動登入可在精靈第 4 步「開啟自動登入…」，預設不開）。

2. 收訊號與下單

  • 訊號一到，跟單中的策略照「目標部位」下單（下單方式預設範圍市價，可在「進階 → 下單」改）；不跟單的策略只記錄訊號部位、不送單。
  • 帳戶區「訊號口數」＝跟單中的策略加總；「庫存」＝券商回傳（已扣掉客戶保留部位）；兩邊一致對帳燈 ✓，不一致 ✗（用「補」處理）。
  • 超過「最大持倉」的單不送，並 TG 通知。

2-1. 本機訊號的規則

  • 下單機直接看這台電腦的訊號檔資料夾（每支策略一個 .txt，檔名＝策略代碼），檔案裡的部位一變就照新部位下單，不經過 GEA 中繼。視窗最上面一行寫「本機訊號」，「接收」燈寫資料夾和最後一筆訊號。
  • 開機第一次讀到的訊號檔只對帳、不下單：檔案部位跟帳上一樣才繼續；不一樣就停這支策略並通知（請人工確認、用「補」處理）。
  • 下面幾種情況拒單（不送單、「接收」燈變紅寫原因、有設 TG 會通知），等這支策略下一個正常訊號才恢復： ① 訊號檔超過 60 秒沒更新（過時）；② 目標部位（口數不分多空）超過最大口數；③ 檔案不是第 0 步選的格式。
  • 只看目標部位、不看一次變動幾口：最大口數 2 時，多 2 口直接反手成空 2 口會照下；目標空 3 口就拒單。
  • 最大口數預設用精靈第 0 步填的數字；在「進階」設了某支策略的「最大持倉」就用那個。

3. 跟單開關（暫停／恢復）

每支策略一個「跟單」開關（開＝訊號會送單；關＝只收訊號、不送單）。開關狀態會存檔，重開電腦、重開下單機都會恢復上次的樣子；每次開／關都會寫記錄並 TG 通知。

動作下單機怎麼做
有部位時把「跟單」關掉先跳確認框；不會平倉。帳上那幾口記成「客戶保留部位」，策略區顯示「客戶保留 多 N 口」；對帳時從庫存扣掉，不會亮 ✗；按「補」也不會去補它
關掉後要平掉保留部位按該商品的「清」（連保留部位一起平，平完保留歸零）；或自己在券商軟體平掉，下單機下次查庫存時發現已經平掉就自動歸零
重新打開時，訊號還有部位不會馬上送單，策略區顯示「等待下一個訊號（目前訊號部位 多 2 口）」；下一則訊號來時直接對齊目標（保留部位算進去，不會重複下）
重新打開時，訊號 0 口立即恢復跟單，下一則訊號照常下單
關掉期間訊號照收、記錄訊號部位，不送任何單
「全部暫停跟單」（策略區右上角）確認一次，把所有跟單中的策略一起關掉；部位照上面「關掉」的規則記成保留，不平倉

建議：要自己在券商軟體處理跟單中的部位，先把那支策略的「跟單」關掉，再操作。

4. 換月（下單機自動處理）

  1. 新開的倉一律下新合約；舊合約部位只會平、不會加。
  2. 反手拆兩張：舊合約部位遇到反手 → 拆成「平舊合約」＋「新合約建倉」。
  3. 自動換倉：照「進階 → 換倉」的時間（預設結算前一交易日 13:45）送「平舊＋建新」；沒成交每分鐘重試，還不成交發 TG 紅色警報，請立刻到券商軟體手動換月。
  4. 換倉一律用範圍市價。第一次遇到結算日，請留意 TG 通知與券商軟體上的部位。

5. 模擬與真單

  • 真單：最上方紅底「⚠ 真單模式」。啟動時會跳確認框，分兩行列出「跟單中：…」「只收訊號：…」，勾「我確認這個帳號只有這台在下單」才能按確定（直接按 Enter＝取消）。
  • 模擬：最上方橘底「模擬環境（假國票，不下單）」，視窗標題寫「（模擬，不下單）」，並有紅色橫幅「模擬模式中：不登入國票、不會下單」。
  • 切換：開桌面「GEA 下單機設定」，選單「工具 → 模擬模式（假國票，不登入、不下單）」打勾＝模擬、取消打勾＝真單；切換後要從第 2 步（國票 API 權限）重跑到第 6 步「啟動」。

六、更新、重開與斷線自動重登

1. 更新新版

GEA 出新版時，左下角會變成「有新版本 → 更新」按鈕（只提示、不會自己更新）：按下去會下載、驗證、關掉下單機、安裝新版、重新啟動並重新對帳；設定、部位全部保留。任何時間都能更新；有部位或在交易時段時會先跳確認框：更新期間約 30～60 秒收不到訊號、不會跟單，裝完自動開回來並對帳（這段時間剛好有新訊號，該策略會先停止並 TG 通知，照通知處理）。按「確定」才更新。裝完開回來的下單機跟平常從桌面開的一樣（一般權限），之後按 X 就能正常關閉。

2. 關閉與重開下單機

  • 按視窗右上角 X：還有跟單中的策略會先問（列出策略與帳上口數，預設「否」）；關掉後不收訊號、不下單，帳上部位不會平倉。確定關閉會寫記錄並 TG 通知。
  • 重開：按兩下桌面「GEA 下單機」。重開後照開機流程對帳（第五章 1）。

3. 國票斷線自動重新登入

國票連線斷掉時，下單機會自己重新登入：斷線 3 秒後試第一次，之後每 30 秒一次，一輪最多 200 次；一輪都失敗就休息 10 分鐘再來一輪（只在交易時段）。重新登入時會向國票重新取得登入憑證（最多每 5 分鐘一次），下單機連開好幾天也不會因為登入憑證過期而登不進去。重登中主畫面「券商」燈是紅的、寫「自動重連中（第 N 次）」；登入恢復會發 TG。

斷線期間收到的訊號不會事後補送（每收到一則都會發 TG）。登入恢復後照開機一樣對帳：訊號跟帳上部位一樣就照常跟單；不一樣就停這支策略、發 TG、不自動追單——請到券商軟體確認實際部位，再按「補」由您決定要不要補單。

4. 不是下單機下的成交（例：在國票 App 手動平倉）

國票回報一筆對不到任何策略的成交時：商品不是任何策略在交易的（例：手動買賣個股期貨）只記在日誌、不查庫存、不發 TG；是策略在交易的商品，下單機會在幾秒內向國票查庫存，跟「帳上部位＋客戶保留部位」比對：一致就沒事；不一致就停這個商品所有跟單中的策略並發 TG，之後訊號回到帳上部位也不會自動恢復。連續 3 次查不到庫存也會全部停下並 TG。處理方式：到券商軟體確認實際部位，照實際部位改好帳本（或請 GEA 協助）後重開下單機；重開後還是不一致，按「補」決定要不要補單。

5. 國票全球財神或其他券商軟體重裝後登入失敗

原因：國票「全球財神」等券商軟體安裝或移除時，會一起重裝 TWCA 憑證元件，把 GEA 下單機要用的 64 位元憑證元件註冊清掉，下單機就登入不了國票（記錄裡會看到「80040154 類別未登錄」）。

券商憑證元件被其他軟體蓋掉時，下單機開啟會跳出這個視窗。

  • 下單機會自己發現：每次開下單機、登入國票之前先檢查；發現被蓋掉就跳出上面的視窗，並發 TG 通知 GEA。
  • 按「修復」：Windows 會跳出權限確認，請按「是」。只會重新註冊 GEA 自己的元件（C:\GEA_om\ibf\WLSecuritiesATLx64.dll），不會動到全球財神或其他券商軟體；修好後自動重新登入國票。
  • 也可以手動修：按兩下 C:\GEA_om\重新註冊憑證元件.bat（會要求系統管理員權限），再重開下單機。
  • 重新執行 GEA 下單機安裝檔、或按「更新」裝新版時，也會自動重新註冊一次。
  • 以後每次安裝、移除或更新全球財神等券商軟體後，開下單機時留意有沒有跳出這個視窗。
