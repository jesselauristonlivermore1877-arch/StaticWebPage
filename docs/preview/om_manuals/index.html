GEA 下單機使用說明（三份）v20261127a

  1. GEA 下單機 使用說明（一般版：本機訊號）
    適用對象：用自己電腦上 MultiCharts／CT PRO 的策略訊號檔，透過國票 API 自動下單的客戶（訊號在自己電腦上，不經過 GEA 雲端）
  2. GEA 下單機 使用說明（VVIP 跟單版：GEA 跟單）
    適用對象：訂閱 GEA 策略、由 GEA 雲端中繼送訊號自動跟單的 VVIP 客戶（需要營業員給的開通碼）
  3. GEA 訊號傳送端 使用說明（策略作者）
    適用對象：把自己的策略訊號送給 GEA 訂閱客戶的策略作者（需要 GEA 給的傳送端開通碼）
