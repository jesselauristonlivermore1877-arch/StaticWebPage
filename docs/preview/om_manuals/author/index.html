一、運作方式與準備

您的 MultiCharts／CT PRO 策略把部位寫進訊號檔，同一台電腦上的 GEA 傳送端一看到部位改變，就把訊號簽章後送到 GEA 雲端中繼您的頻道；中繼再轉給有訂閱的客戶，客戶的 GEA 下單機用他們自己的國票帳戶下單。傳送端只讀訊號檔、不需要券商帳號、不下任何單。

1. 誰收得到

  • 由 GEA 中繼控管：策略要上架、客戶要訂閱那支策略，才會收到。
  • 新策略（新的訊號檔）第一次送上來，中繼自動登記成「下架」；請 GEA 在管理頁上架後，訂閱的客戶才收得到。
  • 客戶收到的是訊號檔那一行的部位（CT PRO 9 欄會先轉成「日期 時間,部位,價格」三欄再送）。

2. 一位作者一個頻道

每位作者用自己的頻道（GEA 開通時告訴您頻道名稱）。不要跟別的作者共用頻道：同一個頻道裡每則訊號有遞增的序號，兩個傳送端各自從 1 開始編號，後送的作者訊號會被中繼當成「重送」丟掉，傳送端還以為送到了，客戶卻收不到。

3. 電腦需求

  • 跟 MultiCharts／CT PRO 同一台、64 位元 Windows 10／11、能上網（https 443）。
  • 整天開著、不睡眠（傳送端開著客戶才收得到訊號）；電腦時間要準（Windows「自動設定時間」打開）。

二、安裝與開通

  1. 下載：GEA 給您的安裝檔下載網址，下載 GEA下單機Setup_20261127a.exe（傳送端和客戶下單機是同一個安裝檔）。按兩下一路「下一步」→「安裝」→「完成」，Windows 問「是否允許」請按「是」。
  2. 完成後自動開啟設定精靈；第 0 步按「檢查」（64 位元 Windows、.NET 4.8 等）。
  3. 按「我有管理者開通碼」，輸入 GEA 給的 8 碼傳送端開通碼（只能用一次；客戶的開通碼不能用在這裡）。兌換成功後，畫面多出「傳送端」選項和「設定傳送端…」按鈕。
  4. 只當傳送端：勾「傳送端」、取消勾「收訊號下單」—— 國票憑證、登入那些第 1～6 步都不用做。這台也要自己下單的話兩個都勾（傳送端和下單機是兩個視窗、兩組狀態燈，設定和記錄分開放）。

範例畫面（假資料）：輸入傳送端開通碼後，第 0 步多出「傳送端」與「設定傳送端…」。

開通資料只用 Windows 加密存在這台電腦（C:\GEA_om\transmit\），只有這台電腦的這個 Windows 使用者解得開。換電腦要請 GEA 重新開通（見第五章 3）。

「檢查」的三項

項目✓ 的意思✗ 怎麼辦
訊號檔找到幾支策略、每個檔最後一行格式都對確認資料夾選對、策略已經寫出訊號檔；格式不對的檔會列出來
簽章金鑰這台的簽章金鑰解得開，客戶的下單機驗得過寫「這台沒有簽章私鑰」或「解不開」：送出去的訊號客戶會拒收，請聯絡 GEA
中繼連線傳送端連得上中繼（只連線、不送訊號）確認能上網；防毒把 C:\GEA_om\ 加例外；公司網路請放行 *.workers.dev 的 443。傳送端已經在跑時不測（免得把它踢掉）

訊號檔格式（兩種都收，自動判斷）

每支策略一個 .txt，檔名＝策略代碼（英文、數字、底線、減號，例 MYSTRAT1.txt）。

格式內容傳送端怎麼讀
MultiCharts 三欄最後一行＝yyyyMMdd HHmmss,部位,價格（例 20261127 093015,-2,23150），三欄都不能空部位＝第 2 欄（負數＝空單）；時間要不早於上一筆
CT PRO 9 欄一行 9 欄、整檔覆寫（例 TXF,MYSTRAT1,1261127,23100,-2,0,23150,2,0）部位＝第 5 欄（負數＝空單）；日期＝第 3 欄；時間＝檔案修改時間；價格＝有部位時第 4 欄進場均價，否則第 7 欄報價

什麼時候送

  • 啟動後每支策略先送一次現況（讓客戶對帳）；之後部位變了才送。
  • 檔案一寫入就讀（另外每 50 毫秒檢查一次當備援）；等檔案寫完才讀，不會讀到寫一半的行。
  • 資料夾設成 …\*.txt 時每 10 秒找一次新檔，新策略不用重開傳送端。
  • 每則訊號都要中繼回「確認」才算送到；沒確認的，重新連上後照順序補送。
  • 訊號檔格式錯（例：欄位空白）→ 保留上一個部位、不送，並發 TG；修好後自動恢復。

四、狀態燈與斷線

按「啟動 GEA 傳送端」後會開一個「GEA 傳送端」視窗（黑底文字視窗），視窗標題就是傳送狀態燈，下面一行一行寫記錄。

狀態意思怎麼辦
● 綠燈（最後中繼確認 HH:mm:ss）連著中繼，訊號都有確認不用處理
● 已連上中繼，還沒送過訊號剛啟動、部位還沒變過不用處理
✗ 沒連上中繼網路斷了或中繼連不上，正在自動重連確認網路；超過 2 分鐘會發 TG
✗ 有訊號超過 20 秒沒有中繼確認連著但訊號沒被確認等自動補送；持續就重開傳送端並聯絡 GEA

斷線時

  • 跟中繼斷線會自己重連，連上後把還沒確認的訊號照順序補送。
  • 上傳連續失敗超過 2 分鐘發 TG「上傳中繼連續失敗」，恢復時再發一則「上傳恢復」。
  • 這台沒有設 Telegram 機器人時，通知經中繼轉給 GEA。
  • 客戶那邊看得到您離線：傳送端關掉或斷線超過約 1 分鐘（或連著但 150 秒沒有任何心跳），訂閱客戶的下單機「接收狀態」會轉黃燈「作者離線」；您連回來就自動轉綠。這段時間客戶收不到新訊號、部位不動。

五、日常使用

1. 開機

傳送端設定勾「開機自動啟動 GEA 傳送端」，登入 Windows 後就會自己開（要登入 Windows 才會啟動）。也可以從精靈第 0 步「設定傳送端…」→「啟動 GEA 傳送端」手動開。

2. 新增、停用策略

  • 新增：讓策略在同一個資料夾寫一個新的 .txt，傳送端 10 秒內自動加入；請 GEA 上架後客戶才收得到。
  • 停用某支策略給客戶：請 GEA 在管理頁下架（傳送端照送，中繼不轉）。

3. 換電腦

開通資料和簽章金鑰只在原來那台電腦、只有原來的 Windows 使用者解得開。要換電腦或換 Windows 使用者，先聯絡 GEA，請 GEA 協助搬移或重新開通，不要兩台同時開傳送端（同一個傳送端代號只留一條連線，新的會把舊的踢掉）。

4. 更新新版

GEA 出新版時，執行新的安裝檔覆蓋安裝；傳送端設定、開通資料、序號都保留。更新期間傳送端會停一下，客戶那邊可能短暫看到「作者離線」，裝完重開傳送端就恢復。
