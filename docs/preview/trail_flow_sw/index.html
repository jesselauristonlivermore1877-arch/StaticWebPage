要看的重點
  1. 下方「族群流向」「族群 × 日熱力圖」「歷史統計」上面多一列子切換：動能｜量能｜法人籌碼｜產業本益比，預設動能（跟現在正式頁一樣）。上面的指數日K與圖層按鈕不變。
  2. 量能、法人籌碼：算法跟動能一樣（族群日值 → 3 日平均 → 翻轉占比 → 全面轉折日），口徑＝族群頁軌跡同一份；全面轉折日跟上方「量能轉折」「籌碼轉折」圖層是同一組日子（程式直接共用）。唯一不同：動能門檻有最低 30%，量能／籌碼沒有（11-16 v2 先定的規則，沒改）。
  3. 產業本益比：本益比沒有逐日翻轉，改畫「各族群本益比在自己歷史第幾分位」熱力圖（紅高綠低、≥ 80 紅框、≤ 20 綠框），資料＝族群頁「產業本益比」同一份 sector_pe.json；沒有轉折日、沒有翻轉統計，頁上有寫。
  4. 名稱候選（請 Evans 選；預覽先不改名）：族群頁也有一個「軌跡流向」，兩個同名容易混。候選：①「轉折流向」（強調全面轉折日）②「族群轉折」（強調很多族群同時翻轉）③「同步轉折」（強調同一天一起翻）。
