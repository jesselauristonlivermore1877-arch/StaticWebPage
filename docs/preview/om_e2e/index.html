版本 20261106a（d10，11-06 出）。用同事的帳號從頭到尾走一遍：管理端產生開通碼 → 下載安裝 → 安裝精靈 0～6 步 → 輸入開通碼 → 連上中繼 → 訊號區只看得到有訂閱的策略 → 帳戶列顯示權益數 → 模擬（或同事自己同意的實單）→ 更新與解除安裝。每一步照表打勾；出錯就照「出錯時截什麼」截圖，連同 C:\GEA_om\logs 整個資料夾一起放進 _inbox 給 W。d9 標記＝d9 才有、d8 沒有的東西（d10 都有）；d10 標記＝d10 新改的地方。

測試前準備

P2測試電腦：Windows 10／11 64 位元，可以用系統管理員身分安裝；關掉其他下單軟體（CT PRO、MultiCharts 下單）。——
P3Evans 決定同事要訂閱哪幾支策略（例：GEA5、GEA6），記下來，第 7 步要核對。——

A. 管理端產生開通碼（Evans 操作）

#要點哪裡應該看到什麼出錯時截什麼✓
1開中繼管理頁 /admin → 按「用 TG 登入」，打開 TG 收到的連結。進到管理頁，看得到客戶清單。整個管理頁（含網址列）。
2「新增客戶」→ 填同事名字、到期日，勾 P3 決定的策略 → 按「產生開通碼」。出現一組開通碼（只顯示一次）；清單多一列，狀態「未啟用」、訂閱的策略跟 P3 一樣。按下去之後的整個畫面（開通碼可以遮掉中間幾碼）。
3把開通碼用 LINE 私訊給同事（不要貼在群組）。——

B. 下載與安裝（同事的電腦）

#要點哪裡應該看到什麼出錯時截什麼✓
4下載 GEA_OM_Setup_20261106a.exe（Evans 給的連結：GitHub Release om-20261106a）。按兩下執行；Windows 跳「保護您的電腦」→「其他資訊」→「仍要執行」。安裝畫面標題寫 20261106a；按「下一步」到「完成」，桌面出現「GEA 下單機」捷徑。任何錯誤視窗；裝完後的「完成」頁。

C. 安裝精靈 0～6 步（裝完會自動開；之後也可以從桌面捷徑開）

#要點哪裡應該看到什麼出錯時截什麼✓
5-0第 0 步「安裝檢查」：按「檢查」。角色保持預設「接收端（客戶）」，不要點「我有管理者開通碼」。每一項綠色 ✓（.NET、國票元件、資料夾權限）；畫面上只有「接收端（客戶）」一個角色。有紅 ✗ 的那一頁（整個精靈視窗）。
5-1第 1 步「憑證檢查」：按「瀏覽」選同事的 .pfx → 輸入憑證密碼 → 按「檢查」。✓ 顯示憑證到期日、身分證遮罩（例 A12****789）。錯誤訊息那一頁（密碼欄會自動遮住）。
5-2第 2 步「國票 API 權限」：填身分證、國票登入密碼 → 按「登入檢查」。✓「已開通，可下單帳號：98*****」。若出現「未開通 API」就停，請同事找營業員開通。連續錯 2 次會停用一段時間，畫面會寫到幾點。結果那一頁；不要截到密碼。
5-3第 3 步「開通碼」：貼上第 2 步拿到的開通碼 → 按「驗證」。✓ 顯示客戶名字、到期日、訂閱的策略（要跟 P3 一樣）。錯誤碼那一頁（例 4013 身分證不符、4014 同策略重複）。
5-4第 4 步「電腦設定」：按「檢查」，照提示修（省電、睡眠、時間同步）。全部 ✓；有 ✗ 的照按鈕修好再檢查一次。還有 ✗ 的那一頁。
5-5第 5 步「模擬演練」：按「開始」。模擬收到訊號、模擬下單、模擬成交都 ✓（不會送出真單）。卡住或 ✗ 的那一頁。
5-6第 6 步「啟動」：確認 0～5 步都通過 → 按「啟動 GEA 下單機」（精靈不會自己啟動）。真單會先跳「真單啟動確認」，要勾確認再按確定。精靈關掉，GEA 下單機主畫面打開。預設是真單（國票正式環境，上方紅底「⚠ 真單模式」）；只有在精靈上方選單勾了「模擬模式（假國票，不登入、不下單）」才是模擬（標題寫「模擬，不下單」、上方黃色橫幅）。所有策略預設「不跟單」。沒打開主畫面時，截精靈最後一頁＋工作列。

D. 主畫面

#要點哪裡應該看到什麼出錯時截什麼✓
6看主畫面上方的連線狀態。「中繼：已連線」綠燈；左下角版本 20261106a。斷線會自己重連（1、2、4…最多 30 秒一次）；連續斷 3 分鐘會發 TG d9。連線狀態那一列；日誌「系統」分頁最後 20 行。
7看策略表（訊號區）。只有P3 訂閱的策略，其他策略看不到。欄位：策略、商品、部位、成本 d9、倍數、跟單、日誌、設定。「跟單」關掉的策略，收到訊號也不得有任何委託或拒單（日誌只記收到、不下單）d10。整張策略表；多出或少了哪支策略寫下來。
8看帳戶區上方的「帳戶」列 d9。模擬模式：「占用保證金 X（估算：期交所原始保證金 × 口數）　權益數 —（模擬沒有券商帳戶）」。切到實單後：「權益數 X　占用保證金 X　可用保證金 X｜HH:mm:ss 更新」，開機、每次成交後、每 60 秒更新。查詢失敗整列變灰，保留上一次的值並寫時間。帳戶列＋日誌「系統」分頁（查詢失敗原因在那裡）。
9模擬：等下一個訊號（或請 Evans 從傳送端送一筆測試訊號）。日誌出現「收到訊號 → 模擬下單 → 模擬成交」；策略表部位變了，「成本」欄出現成交價；帳戶列的占用保證金跟著變（估算）。「跟單」關掉的策略同一筆訊號不得出現任何委託或拒單（只記收到）d10。策略表＋該策略的日誌。

#要點哪裡應該看到什麼出錯時截什麼✓
10（選做，同事本人同意才做）設定 →「跟單」改實單，倍數設最小、商品微台指（TMF）1 口；等訊號或請 Evans 送一筆測試訊號，成交後立刻在國票 App 確認並平倉。國票 App 看得到同一筆委託與成交；主畫面部位、成本、帳戶列（權益數、占用保證金）都在 60 秒內更新。平倉後部位 0、成本變「—」。主畫面＋國票 App 成交回報（帳號可遮）。

E. 更新與解除安裝（d10 任何時間都能更新）

#要點哪裡應該看到什麼出錯時截什麼✓
11（有新版時）主畫面左下角「更新」，任何時間都能按 d10。帶部位按「更新」會跳確認框，按「取消」就不更新（下單機照常跑、版號不變、部位不動）d10；先按一次取消確認這點，再按「確定」走完更新。按確定後：下載 → SHA256 驗證 → 關掉下單機 → 安裝 → 自動開回來，左下角變新版號；TG 收到「✓ 更新完成」。任何一步失敗都會開回舊版並發 TG。C:\GEA_om\logs 的 upgrade_*.log、order_*.log；%TEMP% 裡最新的「Setup Log *.txt」。
12解除安裝：Windows「設定 → 應用程式」→ 找「GEA 下單機」→「解除安裝」。程式與捷徑移除；C:\GEA_om\logs 和設定檔保留（方便再裝）。管理頁上這個客戶的裝置會在下次心跳逾時後顯示離線。解除安裝的錯誤視窗。
13（選做）重新安裝 d10 → 精靈第 3 步用同一組開通碼。同一台電腦、同一個身分證可以重新綁定；換身分證會被擋（4013）。錯誤碼那一頁。
