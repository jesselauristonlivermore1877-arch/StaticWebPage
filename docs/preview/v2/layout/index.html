  • 改法一：圖表最多放大到設計尺寸的 1.25 倍；寬型圖高度限在一屏內，但最少保留 0.75 倍（太矮的螢幕寧可往下捲一點，字不縮到看不清）。

  • 紅字＝主圖仍比一屏高（只剩最矮的 3 種：實際高 512／576／600px）。
