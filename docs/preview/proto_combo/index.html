B. 管理 › 套餐內容（管理者）

成分會先換成可訂閱的策略代碼（格點會先「建立成策略」），再存成一個新套餐，預設下架，確認後才上架。
下架＝不刪、客戶端「推薦套餐」看不到，管理頁照樣可以改內容、重新上架；「刪除」維持原本的按鈕（要確認）。

只列上架的套餐；上面切上架／下架，這裡跟著變。

已訂閱的客戶，套餐下架時怎麼處理（要 Evans 選）

目前會員的訂閱是記「策略代碼」（會員管理的訂閱欄），不是記套餐；所以套餐下架本身不會停掉任何人的訊號。下面是可選的做法：
  1. 照常服務到到期日：已訂閱的照收訊號，只是不能新訂、續訂時請營業員改推別的套餐（程式最少改；W 建議）
  2. 下架即停：下架當下把該套餐的策略從訂閱者身上拿掉（要先記「誰是從哪個套餐訂的」，後端要多一欄）
  3. 指定替代套餐：下架時選一個上架中的套餐，訂閱者自動換過去並發 LINE／TG 通知
