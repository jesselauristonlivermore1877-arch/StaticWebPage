挑法細節

  1. 候選池：全期淨利 > 0，而且 2019～2023 淨利也 > 0（前幾年也要有賺；那幾年指數低、波動小，所以只要求有賺，不要求跟近年一樣多）。
  2. 五個指標各自排序：淨利、風報比、獲利因子（筆數夠多、淨利在前 25%）、勝率（淨利不低於中位數）、期望值（筆數夠多）。筆數門檻用每族資料的 25 分位定。
  3. 每個指標取第 1 名（或前 2 名）；已經被別的指標選中、或跟已選的每日損益相關 ≥ 0.95（飽和區）就往下找下一名。
  4. 合併去重＝這個類型的平均組合；「淨利、獲利因子」表示兩個指標都選到同一支，「（同飽和區）」表示那個指標選到的是同一飽和區的另一格。
  5. SF1S 那族的格點檔 11-13 06:40 會員區更新時寫壞（檔頭是 0），這次略過；已回報總指揮。
