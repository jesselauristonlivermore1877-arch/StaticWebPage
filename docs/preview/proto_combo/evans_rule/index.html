先講結論

    5 步怎麼寫成程式（門檻在跑結果前就寫死）

    1. ① 風報比排序：候選＝風報比在族內前 10%。由第一名往下，風報比低一點（10% 內）但淨利更多的就改選它；再沿參數方向（上下左右）爬淨利，淨利開始遞減就停；停在飽和區就取飽和區中心；同列／同欄淨利沒掉超過 5% 的連續格一起納入（＝用飽和格加重），一區最多 4 格；本步最多 3 區。
    2. ② 淨利排序：候選＝淨利前 10%；風報比低於鄰近 8 格中位數一半的（例：鄰近 0.8～0.9、自己 0.23）剔除；其餘同 ①；本步最多 3 區。
    3. ③ MDD 排序：候選＝回撤最小的 10%；筆數低於族內 25 分位的剔除（MDD 很小但筆數太少）；本步最多 2 格。
    4. ④ 勝率：候選＝勝率前 10%，風報比與期望值都要在族內 72.5 分位以上；加分：勝率高於前面選中格平均、賺賠比稍低、出手少、持倉短；加入後「平均同方向口數」不能變大超過 5%；本步最多 3 格。
    5. ⑤ 年度平均性：組合淨利若有 60% 以上來自 2024～2026，就補 2019～2023 風報比最好、又過 ①～④ 守門的格，最多 2 格。

    共用：跟已選格每日損益相關 ≥ 0.95 算同一格（飽和），不再當新格。平均同方向口數＝每一刻多空口數相加取絕對值，在有部位的時間平均。 v2＝字面版（修過 3 個程式錯誤，門檻沒動）；v3＝解讀變體：爬淨利時風報比不得掉超過起點 10%（把 ① 的「稍低」也套在爬坡上）——這一條是看過 v2 結果才加的，標明有看答案。

    v4＝帶狀（Evans 11-15 晚回答 6 題後）：先找風報比高的連續「帶」（同列橫向或同欄直向、每格風報比在族內前 10%、相鄰差 ≤ 0.05、至少 3 格）；橫帶從飽和段靠淨利低的那端，往淨利遞減方向一格格走，下一格淨利少超過 5%（斷崖）就停、不選斷崖那格，風報比也不能掉超過 10%；直帶挑 1～2 格（風報比最高＋跟它相關最低的互補格）；②③④ 只看帶上的格（帶以外整片弱區不選）；每步不設格數上限；拿掉單族第 ⑤ 步（交給組合層跨族補）。⚠ 訂門檻前看過兩族 −55 列與擴張 0 欄的數字、也已知 Evans 答案；門檻取整數、沿用 v2 的 5%／10%，沒為了對上答案微調。
