根因追蹤（預覽）

市場大幅波動時自動找根因：價格／族群觸發 → 中英日韓搜尋＋免費結構化來源 → 歸因 → 程式逐筆打開出處核對＋用族群漲跌與外資量化傳導。整理公開資訊，非投資建議。
要看的重點
  • 三個盲測案例：程式只拿到日期，自己找根因；第一名是不是真正的根因（不是表面事件）。
  • 「確認」＝有官方或權威出處核對通過，或 2 個以上不同網域核對通過；「市場說法」＝只有非權威出處；未證實的不上網頁（預覽頁收在最下面）。
  • 量化欄：宣稱受影響的族群當天是否真的跌最多（對不上就降級）。
  • 政策回應：程式直接從台灣官方新聞稿列出、打開官方頁核對。
